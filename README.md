# Record Management

## Editing a record

Users with either the **Editor** or **Administrator** or **Writing** or **Editor+++++** role are allowed to modify records.

To alter an existing record:

1. Open the Records page.
2. Select the record you want to change.
3. Click Edit.
4. Update the required fields.
5. Click Save.
6. Confirm The Save

## Deleting a record

Administrators can permanently delete records from the Advanced Actions menu.

Editors can only archive records.
